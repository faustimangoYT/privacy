Política de Privacidad

Última actualización: 15 de Septiembre de 2026

Versión: 1.0

1. Introducción

AI Video Automation ("Aplicación" o "Herramienta") es una aplicación de uso personal para gestionar y publicar contenido en tu propio canal de YouTube. Esta Política de Privacidad explica cómo se recopilan, utilizan, almacenan y protegen tus datos.

Punto clave: AI Video Automation es una herramienta personal de uso exclusivo del propietario del canal. No es un servicio público, no tiene clientes externos, y solo es utilizada por una persona: el propietario autorizado.

2. Quién es el Responsable

Propietario y Responsable de los Datos: Faustino García (propietario del canal de YouTube).

Esta aplicación es un proyecto personal. Los datos se procesan bajo tu autorización mediante OAuth 2.0.

3. Qué es AI Video Automation

AI Video Automation es una herramienta de automatización que:

  • Sube videos a tu canal de YouTube mediante YouTube Data API
  • Gestiona metadatos de videos (títulos, descripciones, miniaturas)
  • Administra playlists y colaboraciones
  • Consulta analíticas y métricas del canal
  • Procesa datos localmente o mediante servicios autorizados

4. Datos Que Recopilamos a través de OAuth 2.0

4.1 Información del Canal

  • ID del canal de YouTube
  • Nombre del canal
  • Descripción del canal
  • Foto del perfil del canal
  • Información de suscriptores (cantidad)

4.2 Información de Videos

  • ID de los videos
  • Títulos y descripciones
  • Etiquetas (tags)
  • Miniaturas
  • Estado de privacidad (privado, no listado, público)
  • Fechas de publicación

4.3 Información de Playlists

  • ID de playlists
  • Nombre y descripción
  • Videos en cada playlist
  • Estado de privacidad

4.4 Métricas y Analíticas

  • Visualizaciones de videos
  • Tiempo de retención promedio
  • Clics en miniaturas
  • Suscriptores nuevos
  • Procedencia de tráfico
  • Datos demográficos de audiencia

4.5 Credenciales y Tokens

  • Token de OAuth (acceso autorizado)
  • Refresh token (para mantener sesión)
  • NOTA: Las contraseñas nunca se solicitan ni se almacenan

5. Finalidad del Procesamiento de Datos

Los datos se utilizan exclusivamente para:

  • Subida de videos: Cargar contenido a tu canal bajo tu autorización
  • Gestión de contenido: Editar metadatos, miniaturas y privacidad
  • Administración de playlists: Organizar contenido en colecciones
  • Consulta de analíticas: Revisar métricas y rendimiento del canal
  • Automatización: Procesar tareas repetitivas autorizadas por ti

6. Dónde se Almacenan los Datos

6.1 Almacenamiento Local

Los datos se almacenan prioritariamente en tu máquina local mediante:

  • Archivos locales (JSON, SQLite)
  • Cache local con TTL (tiempo de vida limitado)
  • Estado de la aplicación en el repositorio privado de GitHub

6.2 Servicios Terceros Autorizados

Cuando es necesario para funciones declaradas:

  • YouTube Data API: Para subir y gestionar videos (servicios de Google)
  • GitHub Actions: Para ejecutar automatizaciones en CI/CD (repositorio privado)
  • Google OAuth 2.0: Para autenticación segura

Aclaración: Los datos solo se comparten con estos servicios cuando es necesario para funcionar. No se comparte información con otros terceros.

7. Período de Retención de Datos

  • Tokens OAuth: Se almacenan mientras la aplicación esté activa y se revoquen manualmente o tras 30 días sin uso
  • Cache de datos: Se elimina automáticamente según el TTL configurado (típicamente 24 horas)
  • Analíticas consultadas: Se mantienen solo mientras sean necesarias para mostrar métricas
  • Registros (logs): Se conservan durante 7 días y luego se eliminan
  • Datos de videos: Se almacenan localmente solo mientras estén en proceso de subida o edición

8. Medidas de Protección

AI Video Automation implementa las siguientes medidas de seguridad:

  • OAuth 2.0: No se solicitan ni se almacenan contraseñas
  • Encriptación de secretos: Las credenciales se enmascararan en logs y trazas
  • Acceso restringido: Solo el propietario autorizado tiene acceso
  • Almacenamiento local: Los datos sensibles se guardan en máquina local, no en servidores públicos
  • Revocación fácil: Puedes revocar el acceso en cualquier momento mediante Google Account
  • Repositorio privado: El código fuente y la configuración están en un repositorio privado de GitHub
  • Sin análisis de terceros: No se usa Google Analytics, Sentry, Mixpanel ni herramientas similares de seguimiento

9. Datos Que NO se Recopilan

  • Contraseñas (nunca se solicitan)
  • Información de métodos de pago
  • Datos de terceros o colaboradores
  • Contenido de comentarios no autorizados
  • Información de navegación web fuera de YouTube

10. No Vendemos Datos

AI Video Automation NUNCA vende, comercializa ni cede datos a terceros. Los datos son propiedad exclusiva del propietario del canal y se utilizan únicamente para funciones autorizadas.

11. Compartición de Datos con Terceros

Los datos se comparten ÚNICAMENTE cuando:

  1. Es necesario para prestar las funciones declaradas (ej: YouTube API para subida de videos)
  2. Está permitido por las políticas de YouTube y Google
  3. Cuenta con tu autorización explícita mediante OAuth 2.0

No se comparte información con terceros no autorizados.

12. Tu Control sobre los Datos

12.1 Revocar Acceso

Puedes revocar el acceso de AI Video Automation en cualquier momento:

  1. Accede a myaccount.google.com/permissions
  2. Busca "AI Video Automation"
  3. Selecciona la aplicación y haz clic en "Eliminar acceso"
  4. Se detendrá cualquier acceso futuro inmediatamente

12.2 Solicitar Eliminación de Datos

Para solicitar la eliminación de datos almacenados localmente:

  1. Contacta al propietario: Faustino García
  2. Especifica qué datos deseas eliminar
  3. Se procederá a eliminar los datos dentro de 30 días

12.3 Acceso a tus Datos

Puedes solicitar una copia de los datos que haya almacenado la aplicación. Proporciona una solicitud verificada al propietario.

13. Cambios en Esta Política

Esta Política de Privacidad puede actualizarse ocasionalmente. Los cambios significativos se notificarán. Tu uso continuado de AI Video Automation implica aceptación de los cambios.

14. Relación con YouTube y Google

AI Video Automation utiliza servicios de Google y YouTube API conforme a sus políticas:

  • Respeta completamente los Términos de Privacidad de Google
  • Cumple con los Términos de API de YouTube
  • No viola las Condiciones de Servicio de YouTube

Nota: Google no es socio de AI Video Automation. Esta es una herramienta personal que simplemente utiliza APIs públicas autorizadas.

15. Conformidad y Estándares

AI Video Automation se compromete a cumplir con:

  • Estándares de seguridad OAuth 2.0
  • Políticas de privacidad de Google y YouTube
  • Mejores prácticas de protección de datos
  • Transparencia en el manejo de información
